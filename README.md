## 🔭 Overview

This platform is a bespoke, hardware-accelerated spatial portfolio and interactive engineering playground built from the ground up for **Kwesi Ankomah-Koranteng**, deployed live at **[kwesikorant.vercel.app](https://kwesikorant.vercel.app)**. 

Unlike conventional flat web portfolios that suffer from frame drops, layout thrashing, and unthrottled DOM mutations, this application proves that rich 3D spatial web software can feel as instant and tactile as native desktop interfaces. Every animation, camera trajectory, touch scrub, and audio cue strictly follows **60/120 FPS compositor standards**, zero DOM reflows, and zero un-culled render loops.

## 🎮 How to Use the Site

The experience is divided into 4 primary spatial stages connected by a single continuous dimensional gateway. You can seamlessly explore using **keyboard hotkeys**, **mouse/trackpad**, or **touch gestures**.

### Keyboard Navigation & Hotkeys

The application includes an extensive physical keyboard navigation layer:

| Key | Action | Description |
|---|---|---|
| <kbd>1</kbd> | **Root Gateway** | Focuses the Root identity node in the 3D scene graph. |
| <kbd>2</kbd> | **Architecture Cluster** | Dollies camera into the Commercial Systems cluster (Nayak ERP). |
| <kbd>3</kbd> | **Featured Projects** | Dollies camera into the Flagship Products cluster (Arcfield Discover). |

### Mouse & Trackpad Controls

#### Stage 0 (Hero // Wireframe Lens Scanner)
- **Cursor Tracking**: Move your mouse across the portrait. A circular lens smoothly tracks your cursor, revealing the underlying 3D cybernetic wireframe scan beneath.
- **Enter Portal Gate**: Click the glowing **ENTER PORTAL GATE &darr;** button or scroll downward to breach into cyberspace.

#### Stage 1 (3D Spatial Canvas // System Node Graph)
- **Node Inspection**: Click any floating node card or its count pill to smoothly dolly the 3D camera into a landscape architecture console.
- **Dolly Zoom (Fly-Through Depth)**: Scroll the mouse wheel up or down to dolly the camera forward/backward along the Z-axis.
- **Stage Overscroll**:
  - Overscrolling **downward** past the maximum depth threshold transits directly into **Stage 2 (Turntable Scrub)**.
  - Overscrolling **upward** past the top threshold transits into **Stage 0 (Hero)**.
- **Free Orbit & Pan**: Click and drag on the 3D canvas backdrop to rotate the camera in 3D pitch/yaw coordinates.
- **Modal Navigation**: When a node is open, click tabs (**Light UI**, **Dark UI**, **Analytics Engine**, **Code Blueprint**), cycle screenshots, or scroll the internal card container.

#### Stage 2 (Kinetic Turntable Mech Scrub)
- **Manual Time Scrub**: Click and drag horizontally across the robot canvas or gently scroll your wheel to scrub the 360° robot from `0%` to `100%` rotation.
- **Auto-Orbit Toggle**: Click the **AUTO-ORBIT** button to engage continuous autonomous rotation.
- **Stage Transit**: Overscrolling downward at `100%` rotation steps to the Finale dossier; overscrolling upward at `0%` rotation returns to the 3D Spatial Canvas.

#### Stage 3 (Settled Terminal Dossier Finale)
- **One-Click Contact**: Click the **junykorant@gmail.com** button to instantly copy the email address to your clipboard with haptic audio confirmation.
- **Return Navigation**: Click **RETURN TO TOP &uarr;** to reset to Stage 0.

### Touch & Mobile Cockpit Gestures

The interface features first-class touch ergonomics tailored for mobile and tablet screens:

- **Touch Reveal**: Drag your finger on the Hero portrait to reveal the wireframe mesh in real-time.
- **Swipe Between Stages**: Swipe vertically (&uarr; / &darr;) anywhere outside interactive cards to transit between stages.
- **Mobile 3D Carousel**: In Stage 1, swipe horizontally (&larr; / &rarr;) across the node cards or tap the counter badge (`01 / 06`) to orbit nodes.
- **Tap to Deep-Dive**: Tap any node card to open the fullscreen system console; tap the close button `(✕)` or outside to dismiss.
- **Turntable Touch Scrub**: In Stage 2, drag horizontally across the robot to manually scrub rotation with directional intent recognition (vertical swipes continue stage scrolling).

### Cockpit HUD & Radar Mini-Map

Located in the top-right and bottom-right corners of the viewport:

1. **Top HUD Bar**:
   - **`AUDIO: ON / OFF`**: Toggle global procedural Web Audio haptics with persistent `localStorage` preference.
   - **`GUIDE ?`**: Opens the keyboard and gesture cheatsheet.
   - **Real-Time Telemetry**: Displays active 3D camera coordinate `POS: [X, Y, Z]`, rotation angles `ROT: [Pitch, Yaw]`, and live FPS monitor (`60/120 FPS`).

2. **Bottom-Right Radar Mini-Map**:
   - **Radar Canvas**: Real-time orthogonal 2D radar displaying all node positions relative to the camera frustum.
   - **Direct Warp**: Click anywhere on the radar grid to warp camera orientation immediately toward that quadrant.
   - **Gimbal D-Pad**: Tap `↑`, `↓`, `←`, `→` to pan the camera; tap diagonal corner buttons (`↖`, `↗`, `↙`, `↘`) to orbit around the center axis.
   - **Zoom Controls**: Tap `+` (Zoom In) or `−` (Zoom Out).

### Synthesized Web Audio Engine

The application contains an entirely procedural, synthesized audio engine (`src/lib/soundEngine.ts`) built with the **Web Audio API**:

- **Zero External Files**: Generates every sound in real-time using mathematical oscillators (`sine`, `triangle`, `sawtooth`) and biquad filters.
- **Zero HTTP Latency**: No audio loading delays, no network requests, and zero 404s.
- **Tactile Soundscapes**:
  - `playKeyClick()`: High-frequency triangle micro-click for keyboard shortcuts.
  - `playWarpSound()`: Sub-bass resonant sine whoosh during camera dolly and portal transit.
  - `playSurgePulse()`: Resonant lowpass sawtooth sweep triggered on <kbd>Space</kbd> key.
  - `playCopySuccess()`: Crystalline dual-harmonic chime ($880\text{ Hz}$ / $1760\text{ Hz}$) on clipboard copy.
  - `playModalOpen()` / `playModalClose()`: Spatial resonant acoustics for modal open and dismiss events.

## ⚡ Motion & Compositor Engineering Protocol

The codebase enforces strict **60/120 FPS Compositor Standards** to eliminate layout thrashing:

1. **Compositor-Only Mutations (Zero Reflow / Zero Repaint)**:
   - Per-frame animation loops, interactive gestures, and scroll progress mutate **strictly** `transform` (`translate3d`, `scale`, `rotate3d`) and `opacity`.
   - Never animates geometry (`width`, `height`, `top`, `left`, `margin`, `padding`).

2. **Layout Thrashing Defense**:
   - All DOM geometry reads (`getBoundingClientRect()`, `offsetTop`, `offsetWidth`) are strictly cached on mount and window resize.
   - Style writes are batched and executed inside a single `requestAnimationFrame` write phase.

3. **Universal Inertia Quenching Engine**:
   - Prevents cascading multi-stage skips caused by trailing macOS trackpad and Windows precision momentum.
   - Detects entry direction, dampens decay momentum, and settles to `IDLE` cleanly.

4. **Viewport Culling (Zero Offscreen Waste)**:
   - Offscreen WebGL render loops, canvas animation frames, and video streams pause automatically via `IntersectionObserver` when outside the viewport (`threshold: 0`).

## 💻 Getting Started & Local Development

### Prerequisites
- **Node.js**: `v18.17.0` or higher (Node 20+ recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/KwesiKorant/portfolio-site.git
   cd portfolio-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Production Build

To validate TypeScript types, verify static assets, and test the optimized production bundle:

```bash
npm run build
npm run start
```

To run the linter:
```bash
npm run lint
```
